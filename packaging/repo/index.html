dstat-go packages

Go implementation of dstat 0.8.0 — installs as /usr/bin/dstat-go, safe next to the distribution dstat package.

Source, documentation and issues: github.com/yupor5/dstat. License: GPL-2.0.

RPM (dnf / yum)

sudo curl -fsSL https://yupor5.github.io/dstat/dstat-go.repo -o /etc/yum.repos.d/dstat-go.repo
sudo dnf install dstat-go        # or: sudo yum install dstat-go
sudo dnf upgrade dstat-go        # later upgrades

Repository base URL: /rpm/ (x86_64, aarch64, i686, armv7hl).

DEB (apt / apt-get)

echo "deb [trusted=yes] https://yupor5.github.io/dstat/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/dstat-go.list
sudo apt-get update
sudo apt-get install dstat-go
sudo apt-get install --only-upgrade dstat-go

Repository base URL: /deb/ (amd64, arm64, i386, armhf).

The repositories are currently not GPG signed, so the RPM repository is configured with gpgcheck=0 and the APT source with [trusted=yes]. Signed repositories can be enabled once a signing key is provided.
